# E-GAMA 神经网络卡片 —— 同一套研究的「拖卡版」实现

> 中文主文档（英文版见 [`README.md`](README.md)）
> 本目录是 [`concrete-strength-prediction`](../README_zh.md) 仓库的**低代码实现**部分：
> 与 [`../src/`](../src) 里的 NumPy 版同一套算法、同一份数据，只是把整条链路搬到了结构设计平台 E-GAMA 的画布上。
> E-GAMA（ProjectPenguin 框架）自定义卡片二次开发 · .NET Framework 4.7.2

在结构工程教学/设计平台 **E-GAMA** 的画布上，用「拖卡 + 连线」搭出完整的深度学习流水线——
数据读取 → 全连接层 → 激活函数 → 训练 → 推理 → 评估 → 多模型对比出图，**不写代码**。

C# 神经网络核心为**手写实现**（He 初始化 / Leaky ReLU / 恒等输出 / MSE / 全批量梯度下降，lr = 1e-4、10000 轮），
与 [`../src/ANN_model.py`](../src) 逐项对齐；**三个线性模型的指标与课程设计报告逐位一致**
（训练集 R² = 0.9352 / 0.9495 / 0.9601）——这是「卡片实现忠实于 Python 研究」的交叉校验。

本目录包含**两套可直接运行的案例**：

| 案例 | 任务 | 模型 | 数据 |
|---|---|---|---|
| **01 · 混凝土抗压强度预测** | 回归（水灰比/粉煤灰/硅灰 → 强度） | 2 个 ANN（3-10-1、3-5-5-1）+ 3 个线性模型（simple/interaction/poly） | 与 [`../data/`](../data) 同一份 66 训练 / 16 测试划分 |
| **02 · 鸢尾花分类** | 非线性分类（两两线性不可分） | 同上 5 个模型 | 分层 120/30，另有 2 特征二分类子集 |

## 卡片一览

| 卡片 | 作用 | 关键端口（入 → 出） |
|---|---|---|
| **输入数据** | 读 CSV（自动识别 UTF-8/GB18030）或内置 demo 数据 | 路径/特征列/标签列/分隔符/内置数据集 → `Dataset` |
| **全连接层** | 声明一层神经元数 | 单元数、偏置、**上游模型** → 层元数据、**模型** |
| **激活函数** | leaky_relu / relu / sigmoid / tanh / linear | 激活类型、上游模型 → 层元数据、模型 |
| **模型构建** | 按连线顺序把层元数据聚合成网络 | 层列表 → `Model` |
| **训练模型** | 全批量梯度下降 + MSE；可接测试集自动出对照 | 模型、数据集、测试集、轮数 10000、学习率 1e-4、种子 42 → 训练结果、**模型报告** |
| **模型推理** | 单样本 / 批量 / Dataset 预测 | 模型、输入 → `double[][]` |
| **模型评估** | R² / MSE / MAE | 真实标签、预测结果 → 三指标、摘要、报告 |
| **线性模型** | 最小二乘正规方程 β=(XᵀX)⁻¹Xᵀy；simple / interaction / poly | 训练集、模型类型、测试集 → 系数、指标、报告 |
| **结果对比** | 汇总最多 5 个模型报告（报告1…报告5 / 汇总链 / 多连线）→ 5 页对比图 | 模型报告 → 摘要 + 图 |
| **张量查看器** | 任意对象一行摘要（调试利器） | 对象 → 文本 |

绘图核心：`ChartMpl.cs`（matplotlib 风带框坐标轴、1-2-5 刻度、散点/折线/柱状/表格/对数轴、图例自动避让）、
`FigureFactory.cs`（计算结果 → 图，不引用 GAMA 类型）、`ChartWindow.cs`（多标签页 + 3200×1900 高清 PNG 导出）。

## 编译与部署

```bash
# 前置：.NET Framework 4.7.2 目标包（VS2019/2022 或 SDK）+ 本机安装 E-GAMA 于 D:\E-GAMA
cd gama-cards/GAMAcard
dotnet build -c Release              # 或 dotnet build -c Release -t:Rebuild 强制走生成后事件
```

生成后事件把产物复制为 `%APPDATA%\nonstructure\Penguin\Cards\GAMAcard.crd`。
复制时 **E-GAMA 必须关闭**（否则 .crd 被占用），复制后需**重启 E-GAMA** 才会加载新卡片；
卡片出现在 **「深度学习」** 分类下。

## 运行案例

1. E-GAMA → **文件 → 打开**（或直接把 .pgz 拖进窗口）载入
   `cases/01-concrete-strength-prediction/case/抗压强度预测.pgz`；
2. 先运行 **结果对比** 卡（会带动上游整条链：数据 → 2 个 ANN + 3 个线性模型 → 对比）；
3. 右键任意可视化卡 →「📊 显示图表窗口」看图，或「💾 导出全部图表 PNG」出图。

- 案例一卡组**数据路径留空**，自动加载内置 demo 数据（与 `data/*.csv` 同一份 66/16 样本），开箱即跑；
- 案例二卡组用的是**相对路径** `data\iris_train.csv`；若你的 GAMA 不解析相对路径，双击卡组里两张
  「文字白板」卡（它们连线到输入数据卡的路径端口），把内容改成 `cases/02-iris-classification/data/…`
  的完整路径即可。

## 结果（本机实测，seed 42）

**案例一 · 混凝土强度**

| 模型 | 训练集 R² | 测试集 R² |
|---|---|---|
| 线性·简单 simple | 0.9352 | 0.9443 |
| 线性·交互 interaction | 0.9495 | **0.9616** |
| 线性·多项式 poly | 0.9601 | 0.9591 |
| ANN 3-10-1 | **0.9675** | 0.9426 |
| ANN 3-5-5-1 | 0.9637 | 0.9300 |

线性三行与 [`../results/`](../results) **逐位一致**；ANN 两行不一致属预期——C# 卡片与 NumPy 版的
He 初始化随机序列不同，且 NumPy 脚本没有给初始化设种子，所以**单次 ANN 数值只是一次抽样**。
同一网络换 9 组初始化重训：测试集 R² = 0.9201…0.9570（均值 0.9481 ± 0.0119），
**9 次全部低于最优线性模型的 0.9616**（见 `cases/02-iris-classification/figures/9次重复实验.png`）。
诚实口径：在这份 66/16 划分上，ANN 的优势**没有被统计上确立**，差异小于初始化的不确定度。

**案例二 · 鸢尾花**：取 versicolor / virginica 两类、只用花瓣长×宽两个特征时，重叠区直线跨不过去——
线性模型准确率约 **94 %**（分错的正是重叠区样本），ANN 学出弯曲边界约 **98 %**（5 个种子 97–99 % 稳定）。
同一套工具链，相反结论：**任务性质决定模型选择。**

## 已知限制

* 仅支持 CSV（Excel 请先另存为 CSV）；损失固定 MSE、优化器固定全批量梯度下降（与课程设计范围一致）；
* 梯度按样本**求和**（不除 N），务必用默认 lr = 1e-4 / 10000 轮，调大会发散；
* ANN 结果依赖初始化（参考 NumPy 脚本的 He 初始化未设种子），C# 卡片在同一种子下可复现；
* E-GAMA 为商业软件，**本目录不包含**其任何文件，仅引用本机安装的 DLL；内容为自有卡片源码、案例、数据与图表；
* `ppt/` 与 `GAMAcard/ppt/` 两套讲演网页的封面页含作者姓名与单位署名，如对外引用请自行确认口径。
