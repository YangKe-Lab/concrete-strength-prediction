# 案例一 · 混凝土抗压强度预测（Concrete Compressive Strength）

> 卡组文件：`case/抗压强度预测.pgz`（21 张顶层卡 + 参数/标签卡，拖进 E-GAMA 窗口或 文件→打开 即可运行）

## 任务

用配合比三项特征（水灰比、粉煤灰掺量、硅灰掺量）预测混凝土 28 天抗压强度，并对比**线性回归**与
**BP 神经网络**两类模型的精度。原始 82 组试验数据按 seed 42 划分 66 训练 / 16 测试；三个特征做
Z-Score 标准化，标签（强度，MPa）保持原值。

**线性模型指标与课程设计报告逐位一致**（训练集 R² = 0.9352 / 0.9495 / 0.9601），说明 C# 卡片实现的
最小二乘与预处理口径正确。

## 数据

| 文件 | 行×列 | 列 |

| `data/train.csv` | 66 × 4 | 水灰比, 粉煤灰, 硅灰, 抗压强度 |
| `data/test.csv` | 16 × 4 | 同上 |

- 前三列为**已标准化**的特征（Z-Score），最后一列为**未标准化**的强度真值（MPa，训练集 5.63–45.66）；
- UTF-8 带 BOM，逗号分隔，首行为列名；
- 卡组中两张「输入数据」卡的数据路径**留空** → 自动加载卡片内置的同一份 demo 数据（66/16），
  其中测试集卡的内置数据集口已设为 `test`。想改用自己的 CSV：把路径端口接到文字卡并填完整路径。

## 画布上的 5 个模型

| # | 模型 | 结构 / 类型 | 名称（图例） | 关键参数 |
|---|---|---|---|---|
| 1 | ANN Model1 | 3-10-1（Dense 10 → leaky_relu → Dense 1） | `ANN Model1` | epochs 10000, lr 1e-4, seed 42 |
| 2 | ANN Model2 | 3-5-5-1（Dense 5 → leaky_relu → Dense 5 → leaky_relu → Dense 1） | `ANN Model2` | 同上 |
| 3 | 线性模型 | `simple` | `线性模型1` | 最小二乘 |
| 4 | 线性模型 | `interaction` | `线性模型2` | 最小二乘（含交互项） |
| 5 | 线性模型 | `poly` | `线性模型3` | 最小二乘（含平方项） |

5 张模型卡的「模型报告」分别接到 **结果对比** 卡的 **报告1…报告5**（一模型一口，不需要多连线）；
层与层之间用「上游模型 → 模型」串联成链（详见 `GAMAcard/连线方案.md` §2.5）。

## 结果

| 模型 | 训练集 R² | 测试集 R² |
|---|---|---|
| 线性·简单 | 0.9352 | 0.9443 |
| 线性·交互 | 0.9495 | **0.9616** |
| 线性·多项式 | 0.9601 | 0.9591 |
| ANN Model1 (3-10-1) | **0.9675** | 0.9426 |
| ANN Model2 (3-5-5-1) | 0.9637 | 0.9300 |

**怎么读这组数**：训练集上 ANN 赢（+0.02 量级，稳定）；测试集上 ANN 输给交互线性模型 0.019——而这
0.019 小于换初始化带来的波动（9 次重复：0.9481 ± 0.0119，**0 次**超过 0.9616）。所以正确结论是
「泛化能力在 16 个测试样本上无法区分优劣」，而不是「ANN 更好」或「ANN 不行」。
