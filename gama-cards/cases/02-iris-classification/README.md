# 案例二 · 鸢尾花分类（Iris · 线性不可分）

> 卡组文件：`case/鸢尾花案例.pgz`（与案例一同一套卡片结构，换数据、换标题）

## 这个案例要证明什么

案例一（混凝土强度）的诚实结论是「神经网络没赢过线性模型」。那是不是神经网络不行？
**不是**——是那份数据太"乖"，规律接近线性。本案例换一个教科书级的**非线性**任务来验证：
线性模型有结构性极限，神经网络能突破。

## 为什么鸢尾花是"非线性"的

经典 Fisher (1936) 数据集，150 组、4 个特征、3 个类别。关键在于：

- **setosa（0）与另外两类线性可分**——花瓣尺寸差异巨大，一条直线就能分开；
- **versicolor（1）vs virginica（2）线性不可分**——两组的花瓣尺寸范围**部分重叠**，任何直线都分不干净。

只保留 versicolor/virginica、只取**花瓣长度 × 花瓣宽度**两个特征时，重叠区在二维图上一眼可见：
这就是"直线永远跨不过去的坎"（图见 `figures/鸢尾花_决策边界对比.png`）。

## 数据

| 文件 | 行×列 | 说明 |
|---|---|---|
| `data/iris.csv` | 150 × 5 | 全量：花萼长度, 花萼宽度, 花瓣长度, 花瓣宽度, 品种类别 |
| `data/iris_train.csv` | 120 × 5 | 分层 8:2 训练集（每类 40） |
| `data/iris_test.csv` | 30 × 5 | 分层 8:2 测试集（每类 10） |
| `data/iris2_train.csv` | 80 × 3 | **二分类子集**：花瓣长度, 花瓣宽度, 品种类别（0/1） |
| `data/iris2_test.csv` | 20 × 3 | 上述子集的分层测试集 |

- 类别映射：0 = Iris-setosa（山鸢尾）、1 = Iris-versicolor（变色鸢尾）、2 = Iris-virginica（维吉尼亚鸢尾）；
- `iris2_*.csv` 里 0/1 对应 versicolor / virginica，专门用于二维决策边界演示；
- 数据来源：UCI Machine Learning Repository。

## 演示口径（推荐二分类 0/1 回归式）

1. 取 versicolor + virginica，标签改 0/1，**当回归做**：预测值 > 0.5 判为 1，统计**准确率**；
2. 线性模型：准确率约 **94 %**（分错的恰好是重叠区的 6 个样本）；
3. ANN 2-10-1：准确率约 **98 %**（5 种随机初始化 97–99 % 稳定）；
4. 结论口径：*"直线在重叠区没有解，神经网络用弯曲边界把两类分开了——这是线性模型的结构性极限，
   不是数据问题。"*

> 超参细节：本案例目标量级是 0/1（不是 30 MPa），梯度小约两个数量级，因此 ANN 用 **lr = 1e-3、
> 30000 轮**（与案例一的 lr = 1e-4、10000 轮不同）。顺带说明"模型容量要匹配任务"。
