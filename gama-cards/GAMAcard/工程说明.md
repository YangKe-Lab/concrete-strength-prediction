# GAMAcard —— 基于 E-GAMA 的 ANN 混凝土抗压强度预测卡片工程

本项目是 E-GAMA（ProjectPenguin 框架）的自定义卡片二次开发工程，用于在 GAMA 可视化画布中搭建 BP 神经网络，完成**「基于 ANN 的混凝土抗压强度预测」**课程设计任务。网络算法与 Python 版 `ANN_model.py`（He 初始化 / Leaky ReLU 隐藏层 / 线性输出层 / MSE 损失 / 全批量梯度下降）完全对齐。

> **详细使用教程请阅读 [`使用文档.md`](使用文档.md)（必读）**

## 项目结构

```
GAMAcard/
├── GAMAcard.slnx / GAMAcard.csproj   工程文件（.NET Framework 4.7.2）
├── 使用文档.md                        ★ 完整使用教程（画布搭建步骤、参数、FAQ）
├── Cards/
│   ├── InputDataCard.cs    输入数据卡：加载 CSV 数据集（UTF-8/GB18030 编码自动识别；路径留空=内置课程设计 train/test 真实数据）
│   ├── DenseLayerCard.cs   全连接层卡：声明隐藏层神经元数
│   ├── ActivationCard.cs   激活函数卡：leaky_relu(默认)/relu/sigmoid/tanh/linear
│   ├── ModelBuilderCard.cs 模型构建卡：按连线顺序聚合网络结构
│   ├── TrainModelCard.cs   训练模型卡：创建并训练 ANN（可连测试集自动出训练/测试对照图）
│   ├── PredictCard.cs      模型推理卡：单样本/批量/Dataset 预测
│   ├── EvaluateCard.cs     模型评估卡：计算 R²/MSE/MAE
│   ├── LinearModelCard.cs  线性模型卡：最小二乘正规方程（simple/interaction/poly）
│   ├── CompareCard.cs      ★ 结果对比卡：多模型精度汇总对比（5 页对比图）
│   ├── TensorViewerCard.cs 张量查看器卡：任意对象摘要（调试利器）
│   ├── SimpleNN.cs         纯 C# 手写神经网络核心（与 Python 版逐项对齐）
│   ├── NNTypes.cs          卡片间传递的强类型定义
│   ├── ReportTypes.cs      ★ ModelReport：模型报告（对比卡的输入契约）
│   ├── ChartMpl.cs         ★ matplotlib 风格 2D 绘图工具（坐标轴/散点/柱状/表格/横向条形）
│   ├── FigureFactory.cs    ★ 图表工厂：把计算结果变成「好看的图」（不依赖 GAMA 类型，可离线渲染自检）
│   ├── ChartWindow.cs      图表窗口（多标签页 + 一键导出 3200×1900 高清 PNG）+ 旧版 2D 绘图工具
│   └── NNVisualizer.cs     E-GAMA 三维预览图元（点/线/文字）构建工具
├── presentation.html               教学幻灯片演示系统
└── README.md                       本文件
```

## 可视化：好看的图 + 一键导出 + 结果对比

| 能力 | 用法 |
|---|---|
| 看图表 | 右键卡片 →「📊 显示图表窗口」（每个图表页一个标签页，改参数重跑自动刷新） |
| 导出图片 | 右键卡片 →「💾 导出全部图表 PNG」，输出 **3200×1900** 高清 PNG 到 `桌面\GAMA图表\` |
| 结果对比 | 把各模型卡的「模型报告」都连到 **结果对比卡**，一次运行生成 5 页对比图（精度柱状图 / 全模型散点对照 / 逐样本折线 / 损失曲线 / 指标明细表 + 排名结论） |

图表风格**刻意复刻课程设计里的 matplotlib 图**：蓝=训练集、绿=测试集、红虚线=理想线 y=x、灰虚线网格、带框坐标轴、标题带 R²。
详见 [`使用文档.md`](使用文档.md) 第 12 节。

## 开发环境要求

- **IDE**: Visual Studio 2019/2022 或 VS Code（.NET SDK 环境）
- **目标框架**: .NET Framework 4.7.2 (`net472`)
- **E-GAMA 安装路径**: `D:\E-GAMA`
  - 核心引用：`D:\E-GAMA\ProjectPenguin.dll` 等（见 csproj，均为 `Private=false` 不随包复制）

## 编译与部署

1. **编译**：

   ```bash
   dotnet build -c Release
   ```

   或在 Visual Studio 中选择 `Release` 编译。

2. **自动部署**：工程内置生成后事件，编译成功后自动把产物复制为 GAMA 自定义卡片：

   ```text
   %AppData%\nonstructure\Penguin\Cards\GAMAcard.crd
   ```

3. **加载**：启动 GAMA，卡片管理器自动识别并在「深度学习」分类下出现全部卡片。

## 调试指南（断点命中）

1. 项目已配置 F5 启动外部程序调试：
   - 启动程序：`D:\E-GAMA\NsClientSideLicenseManagerWpf.exe`
   - 工作目录：`D:\E-GAMA`
2. 若断点呈灰色无法命中：
   - VS 菜单 → **调试 → 选项 → 调试 → 常规** → 取消勾选 **“启用仅我的代码 (Just My Code)”**
3. 按 F5 启动调试即可命中各卡 `Build` 方法内的断点。
