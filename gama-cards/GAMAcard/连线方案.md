# GAMAcard 完整连线方案 —— 混凝土抗压强度预测（5 模型对比）

> 工程 `gama-cards/GAMAcard`｜卡片分类：**深度学习**
> 目标：一张画布跑出课程设计全部 5 个模型（ANN①3-10-1、ANN②3-5-5-1、线性 simple/interaction/poly），
> 并生成训练集+测试集指标与 5 页对比图。

---

## 0. 卡片清单（共 18 张 = 2 数据 + 12 ANN + 3 线性 + 1 对比）

| # | 卡片 | 张数 | 用途 |
|---|---|---|---|
| 1 | 输入数据 | 2 | A=训练集(内置 train 66 样本)、B=测试集(内置 test 16 样本) |
| 2 | 全连接层 | 5 | ANN① Dense(10)+Dense(1)；ANN② Dense(5)+Dense(5)+Dense(1) |
| 3 | 激活函数 | 3 | ANN① 1 个；ANN② 2 个（都填 leaky_relu） |
| 4 | 模型构建 | 2 | 按连线顺序把层元数据聚合成网络结构 |
| 5 | 训练模型 | 2 | 训练 ANN + 算训练/测试指标 + 出图 + 出模型报告 |
| 6 | 线性模型 | 3 | simple / interaction / poly 三个线性回归 |
| 7 | 结果对比 ★ | 1 | 汇总 5 个模型报告 → 5 页对比图 |
| 8 | 张量查看器 | 0~2 | 可选，调试/截图用 |

> 卡片表面显示的是**端口短名**（如「层元数据」「模型报告」）；点击/悬停端口可看到完整说明。
> 有默认值的端口（如 epochs、模型类型、模型名称）**直接填值即可，不必连线**。

## 1. 画布布局建议

```
 [输入数据 A] 训练集66            ┌─ [全连接层 10] ─┐
  数据集 ─┬───────────────────────┤  [激活函数 leaky] ├─ [模型构建 ANN_Model1] ─ [训练模型 ①]
          │                       └─ [全连接层 1] ──┘        （模型名称: ANN Model1）
          │
 [输入数据 B] 测试集16            ┌─ [全连接层 5] ─┐
  数据集 ─┼───────────────────────┤  [激活函数 leaky] ├─ [模型构建 ANN_Model2] ─ [训练模型 ②]
          │                       │  [全连接层 5]    │        （模型名称: ANN Model2）
          │                       ├  [激活函数 leaky] │
          │                       └─ [全连接层 1] ───┘
          │
          ├─ [线性模型① simple]      （模型名称: 线性·简单）
          ├─ [线性模型② interaction] （模型名称: 线性·交互）
          └─ [线性模型③ poly]        （模型名称: 线性·多项式）
                                          ↓ 5 个「模型报告」都连到 ↓
                                   [结果对比 ★]  → 5 页对比图 + 导出 PNG
```

布局原则：**左=数据、中=模型链、右=结果对比**。每组 ANN 的层卡片按 Dense→Activation→Dense 从上到下排，视觉即结构。

## 2. 分组接线（照抄）

### A. 数据层（2 张「输入数据」）

| 卡片 | 端口 | 填值 | 说明 |
|---|---|---|---|
| A 训练集 | 路径 | **留空** | 留空才加载内置数据 |
| | 内置数据集 | **留空**（默认 train） | 66 样本训练集 |
| | 其余端口 | 默认 | 批大小/验证比例当前版本不生效 |
| B 测试集 | 路径 | **留空** | |
| | 内置数据集 | **test** | 16 样本测试集 |

> 想用自己导出的 CSV：把「路径」填成 `...\train.csv` / `...\test.csv`（内置数据集端口则不起作用）。

### B. ANN 模型①（3-10-1）

> **层的两种接法（必读）**：本平台一个输入端口**默认只接一根线**（拖第二根会把第一根顶掉）。
> - **接法一（推荐，1 对 1 串联）**：层卡新增了「上游模型」入 /「模型」出两个端口，把 5 张层卡串成一条链，最后一个「模型」直接接**训练卡的「模型」端口** —— 见 §2.5。
> - **接法二（并行多连线）**：各层卡的「层元数据」并联到模型构建卡的「层列表」，需要右键端口 →「**添加多个数据连接**」逐根加（平台自带菜单项），加的顺序 = 网络层序。
>
> 两种接法二选一，**不要同时用**（会重复计数）。

| 卡片 | 端口 | 填值 / 连到 |
|---|---|---|
| 全连接层 D1 | 单元数 | **10** |
| 激活函数 A1 | 激活类型 | **leaky_relu** |
| 全连接层 D2 | 单元数 | **1**（输出层，**不接激活卡** → 自动 linear） |
| 模型构建 MB1 | 模型名 | **ANN_Model1** |
| 训练模型 T1 | 迭代轮数 / 学习率 / 随机种子 | 10000 / 0.0001 / 42（默认，与 Python 版一致） |
| | 模型名称 | **ANN Model1** |

连线：
1. `D1.层元数据 → MB1.层列表`
2. `A1.层元数据 → MB1.层列表`
3. `D2.层元数据 → MB1.层列表`
   → **这三根线的先后顺序就是网络顺序**：Dense(10) → Activation(leaky_relu) → Dense(1)
4. `MB1.模型 → T1.模型`
5. `A.数据集 → T1.数据集`
6. `B.数据集 → T1.测试集`
7. （可选装饰线，让画布连成一条链）`D1.输出张量 → A1.输入张量`、`A1.输出张量 → D2.输入张量`

### C. ANN 模型②（3-5-5-1）

| 卡片 | 端口 | 填值 |
|---|---|---|
| 全连接层 D3 | 单元数 | **5** |
| 激活函数 A2 | 激活类型 | **leaky_relu** |
| 全连接层 D4 | 单元数 | **5** |
| 激活函数 A3 | 激活类型 | **leaky_relu** |
| 全连接层 D5 | 单元数 | **1**（不接激活卡） |
| 模型构建 MB2 | 模型名 | **ANN_Model2** |
| 训练模型 T2 | 模型名称 | **ANN Model2**；其余默认 |

连线：
8. `D3.层元数据 → MB2.层列表`
9. `A2.层元数据 → MB2.层列表`
10. `D4.层元数据 → MB2.层列表`
11. `A3.层元数据 → MB2.层列表`
12. `D5.层元数据 → MB2.层列表` （顺序：5 → leaky → 5 → leaky → 1）
13. `MB2.模型 → T2.模型`
14. `A.数据集 → T2.数据集`
15. `B.数据集 → T2.测试集`

### D. 线性模型（3 张）

每张都是同一种接法，只有「模型类型」「模型名称」不同：

| 卡片 | 训练数据 | 模型类型 | 测试集 | 模型名称 |
|---|---|---|---|---|
| 线性模型① | `A.数据集` | **simple** | `B.数据集` | **线性·简单** |
| 线性模型② | `A.数据集` | **interaction** | `B.数据集` | **线性·交互** |
| 线性模型③ | `A.数据集` | **poly** | `B.数据集` | **线性·多项式** |

（模型类型也可写中文别名：简单线性 / 交互 / 多项式）

### E. 结果对比 ★（1 张）

**三条汇总路线任选一条**（卡片三种入口都支持，会按引用自动去重）：

| 路线 | 接法 | 说明 |
|---|---|---|
| ① **推荐·最简单** | 5 张模型卡的「模型报告」分别接到对比卡的 **「报告1」「报告2」…「报告5」** | 每个口只接一根线，**不需要任何多连线操作** |
| ② 汇总链 | 模型卡 A.报告汇总 → B.上游汇总 → … → 对比卡.**模型集合** | 每根 1 对 1，顺序无所谓 |
| ③ 多连线 | 5 根「模型报告」全接到 **「多连线报告」** 端口 | 需右键端口 →「添加多个数据连接」 |

| 端口 | 类型 | 说明 |
|---|---|---|
| 报告1 ~ 报告5 | ModelReport | 一模型一个入口（路线①） |
| 多连线报告 | ModelReport（ListByList） | 同口多根线（路线③） |
| 模型集合 | ModelSet | 报告汇总链的末端（路线②） |
| 对比标题 | string | 默认「混凝土抗压强度预测」 |
| 对比摘要 | 出 | 各模型指标 + 自动排名 + 结论 |

### F. 可选：张量查看器

把想看的东西接到「对象」端口 → 输出一行摘要（Dataset 维度 / Model 层列表 / TrainingResult 收敛 / LinearResult 系数 / **ModelReport 指标**）。用于画布上直接截图。

## 2.5 层卡片怎么连（方案 B：1 对 1 串联，推荐）

每张「全连接层」「激活函数」卡都新增了两个端口（追加在末尾，不影响旧画布）：

| 端口 | 方向 | 说明 |
|---|---|---|
| **上游模型** | 入（可选） | 接上一张层卡的「模型」输出 |
| **模型** | 出 | = 上游各层 + 本层（有序），可直接接训练卡的「模型」端口 |

**3-10-1（模型一）串联接法**：

```
全连接层(10).模型 → 训练模型.模型
```
（只有一层隐藏层时，直接接训练卡即可）

**3-5-5-1（模型二）串联接法**：

```
全连接层①(5).模型 ──→ 激活函数①.上游模型
激活函数①.模型   ──→ 全连接层②(5).上游模型
全连接层②.模型   ──→ 激活函数②.上游模型
激活函数②.模型   ──→ 全连接层③(1).上游模型
全连接层③.模型   ──→ 训练模型.模型          ← 最后一根进训练卡
```

每根线都是 1 对 1，**完全不依赖平台的多连线**；顺序由链条本身决定，不会连错。
链条里的层序 = 连线方向：`Dense(5) → 激活 → Dense(5) → 激活 → Dense(1)`。

**还想用模型构建卡？** 保留「层元数据 → 层列表」那条并行接法就行（需要右键端口「添加多个数据连接」逐根加）；
串联接法可以不拖模型构建卡，训练卡日志照样会打印 `结构=3-5-5-1`。

## 2.6 五个模型怎么汇总（方案 B：报告汇总链，推荐）

和层链同一个思路：每张模型卡（训练模型 / 线性模型 / 模型评估）都新增了两个端口

| 端口 | 方向 | 说明 |
|---|---|---|
| **上游汇总** | 入（可选） | 接上一张模型卡的「报告汇总」 |
| **报告汇总** | 出 | = 上游各模型 + 本模型（有序），可直接接下一张模型卡或结果对比卡 |

**五模型对比接线（每根 1 对 1，顺序无所谓，对比卡会自动按 R² 排序）**：

```
ANN Model1(训练卡①).报告汇总 → 训练卡②.上游汇总
训练卡②.报告汇总              → 线性模型①.上游汇总
线性模型①.报告汇总            → 线性模型②.上游汇总
线性模型②.报告汇总            → 线性模型③.上游汇总
线性模型③.报告汇总            → 结果对比卡.模型集合      ← 最后一根进对比卡
```

**另一种接法**：各模型卡的「模型报告」逐根接到结果对比卡的「模型报告」端口（ListByList 多连线，
需要右键端口 →「添加多个数据连接」逐根加）。两种方式可以混用，卡片会按引用自动去重。

> ⚠️ 同一个模型不要既在链里出现、又单独接一根「模型报告」——虽然会去重，但容易看混。

## 3. 运行顺序与预期日志

1. **先运行「结果对比」卡**（会自动带动上游）；若日志显示某个上游卡没执行，就从数据卡开始，自上而下依次运行一遍。
2. 逐卡核对日志（这是判断"真的跑对了"的唯一依据）：

| 卡片 | 期望日志关键字 |
|---|---|
| 输入数据 A | `已加载内置【训练集】demo 数据（课程设计 train.xlsx，66 样本×3 特征…` |
| 输入数据 B | `已加载内置【测试集】demo 数据（课程设计 test.xlsx，16 样本×3 特征…` |
| 训练模型 ① | `训练完成。模型=ANN Model1，结构=3-10-1（激活:leaky_relu/linear）…训练集 R²=0.96xx … 测试集 R²=0.94xx` |
| 训练模型 ② | `结构=3-5-5-1` + 同样两组指标 |
| 线性模型② | `LinearModelCard: 线性·交互（interaction）训练完成，训练集(n=66) \| R²=0.9495 …` |
| 结果对比 | `模型对比（共 5 个，按测试集 R² 降序）… 结论：xxx 综合表现最好` |

3. **看图 / 出图**：右键任意可视化卡片 →
   - 「📊 显示图表窗口（可导出 PNG）」：输入数据 2 页、训练模型 4 页、线性模型 3 页、结果对比 5 页；改参数重跑会自动刷新
   - 「💾 导出全部图表 PNG」：出 3200×1900 高清 PNG 到 `桌面\GAMA图表\`

### 参考数值（本机 C# 实测，可用来判定是否跑对）

| 模型 | 训练集 R² | 测试集 R² |
|---|---|---|
| 线性·简单 | 0.9352 | 0.9443 |
| 线性·交互 | 0.9495 | 0.9616 |
| 线性·多项式 | 0.9601 | 0.9591 |
| ANN Model1 (3-10-1) | 0.9675 | 0.9426 |
| ANN Model2 (3-5-5-1) | 0.9637 | 0.9300 |

前三个与课程设计报告**逐位一致**；ANN 因随机初始化序列不同（C# Random vs numpy），数值同量级但不会逐位相同，**固定 seed 后 C# 自身每次可复现**。

## 4. 可选分支：推理 + 评估（交叉验证用）

```
模型推理 P1：模型 ← T1.训练结果      输入数据 ← B.数据集   → 预测结果
模型评估 E1：真实标签 ← B.数据集     预测结果 ← P1.预测结果    模型名称 = ANN Model1 测试集
```

- 期望：E1 输出的 R²/MSE/MAE 与 T1 日志里"测试集"的数值**完全一致**（同一模型、同一测试集，两条独立计算路径）。
- **⚠️ 别重复连**：E1 也会输出「模型报告」。如果把 T1 和 E1 的报告都连到对比卡，对比图里会出现两个 ANN Model1。
  **二选一**：要么用 T1 的报告（推荐，训练卡已自带测试集评估），要么用 E1 的报告（只做评估时用）。

## 5. 最小验证版（想先跑通 3 分钟版）

只拖 **4 张卡**：

```
[输入数据 A] 数据集 → [训练模型]（模型端口不接 = 自动 3-10-1；不接测试集）
                         训练结果/模型报告 → [结果对比]
[输入数据 B] test 数据集 → 训练模型.测试集
```

- 训练模型卡「模型」端口**留空不接**时，自动使用课程设计默认结构 `{输入维, 10, 输出维}` = **3-10-1**。
- 先跑通 → 再补模型构建卡与第二个网络 → 最后加线性模型，逐步验证。

## 6. 排错速查

| 现象 | 原因 / 处理 |
|---|---|
| 训练卡报 `数据端口"数据集"收集数据失败，请确保数据连接` | 「数据集」端口必须连；有默认值的端口才可空着 |
| PLog 里 `数据类型转换失败（从 String 至 Model）`，但卡片日志无报错 | 旧画布残留字符串连线（端口类型改过）→ 删掉旧卡与文字卡，重新拖入连线 |
| 结构变成 3-10-1-1 之类 | 末层 Dense 单元数 ≠ 标签维数（1）→ 会自动追加输出层并警告；把末层单元数改成 1 |
| 结构顺序不对 | 层列表连线顺序错：必须 Dense → Activation → Dense 依次连到模型构建卡 |
| 对比图只出现 1 个模型 | 报告端口只接了 1 根线；要 5 根线进同一个端口 |
| 对比图出现重复的同一模型 | 训练卡与评估卡的报告都连了 → 二选一 |
| 图表窗口空白 | 先运行卡片生成图表数据，再点右键菜单 |
| 导出 PNG 没反应 / 编译报 MSB3073 复制失败 | E-GAMA 正在运行占用 `.crd` → 关闭 E-GAMA（确认 EduLauncher 进程退出）后重新编译；新 `.crd` 需**重启 E-GAMA** 才加载 |
| 卡片列表里没有新卡片「结果对比」 | `.crd` 已更新但没重启 E-GAMA |
