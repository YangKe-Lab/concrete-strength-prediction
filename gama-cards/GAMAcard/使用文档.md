## 1. 总体方案

整个课程设计在 GAMA 中分两段完成：

```
┌─────────────────────────────┐        ┌──────────────────────────────────────────┐
│  第一段：GAMA 内置 Python 卡片 │        │  第二段：本项目 C# 卡片流水线               │
│  （数据预处理）                │        │                                          │
│                             │        │  输入数据 → 全连接层/激活函数 → 模型构建     │
│  data.xlsx                  │        │      ↓           ↓              ↓         │
│   ├ 缺失值处理(均值/中位数填充) │ ────→  │   Dataset        Model ──→ 训练模型        │
│   ├ Z-Score 标准化(3个特征)    │ 导出   │   (train.csv)                 ↓          │
│   └ 随机划分 82 组            │ CSV    │                            TrainingResult │
│      → train.csv (66组)      │        │                               ↙          │
│      → test.csv  (16组)      │        │                    模型推理 → 模型评估       │
└─────────────────────────────┘        └──────────────────────────────────────────┘
```

**职责划分**：

| 工作 | 由谁完成 |
|---|---|
| 缺失值填充、Z-Score 标准化、训练/测试集划分 | GAMA 内置 **Python 卡片**（沿用你 preprocess.py 的逻辑） |
| 读入标准化后的 CSV、搭网、训练、预测、评估 | 本项目 **C# 卡片** |

## 3. 数据准备

### 3.1 文件要求

| 文件 | 内容 | 规模 |
|---|---|---|
| `train.csv` | 训练集：水灰比,粉煤灰,硅灰,抗压强度 | 66 行 × 4 列 |
| `test.csv` | 测试集：同上列顺序 | 16 行 × 4 列 |

- 前 **3 列为特征**（已由 Python 卡片做 Z-Score 标准化），**最后 1 列为标签**（抗压强度原始值）；
- 首行为表头（也可无表头，用"包含表头"端口控制）；
- 特征列/标签列不按默认顺序排时，可用「特征列」「标签列」端口指定列名或索引。

### 3.2 从 Excel 导出 CSV

在 Excel/WPS 中打开预处理产物 → **另存为 → 格式选 "CSV UTF-8 (逗号分隔)(*.csv)"**。
本项目的输入数据卡会自动识别 UTF-8 / GB18030 编码，普通 "CSV (逗号分隔)" 也不会乱码。

### 3.3 注意

- 标签列（抗压强度）**不要标准化**——与 Python 版保持一致，这样评估指标的量纲才有物理意义；
- 标准化参数（均值/标准差）必须来自训练集，且测试集要用同一组参数变换——这一步由 Python 卡片统一完成后导出，画布内无需再处理。

## 4. 卡片速查表

所有卡片位于分类 **深度学习** 下。

### 输入数据（InputData）

加载 CSV 为 Dataset。路径留空时输出内置 XOR 示例数据。

| 端口 | 方向 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| 数据路径 | 入 | string | "" | CSV 完整路径；留空生成 XOR 示例 |
| 批大小 | 入 | int | 32 | 【当前版本不生效】全批量训练无需设置 |
| 验证集比例 | 入 | double | 0.2 | 【当前版本不生效】请在 Python 卡片中预先划分 |
| 特征列 | 入 | string | "" | 列名或 0 起始索引逗号分隔；留空=除最后一列外全部 |
| 标签列 | 入 | string | "" | 留空=最后一列 |
| 包含表头 | 入 | bool | true | 首行是否为列名 |
| 分隔符 | 入 | string | "," | 单字符分隔符 |
| 内置数据集 | 入 | string | "train" | **路径留空时生效**：`train`=课程设计训练集(66样本) / `test`=课程设计测试集(16样本) |
| 数据集 | 出 | Dataset | - | 特征 X + 标签 Y |

> **图表**：右键卡片 →「显示图表窗口」可看 2 页图：① 四联直方图（复刻课程设计 `data.png`）② 特征-强度散点（含最小二乘趋势线）。
>
> **做训练/测试对照**：拖两张输入数据卡，其中一张把「内置数据集」端口填 `test`（或路径指向 test.csv），即可给训练卡/线性模型卡提供测试集。

### 全连接层（Dense）

声明一个隐藏层。**末层 Dense 默认线性激活**（回归输出），其余默认 leaky_relu。

| 端口 | 方向 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| 输入张量 | 入 | Tensor | - | 占位连线，可不接 |
| 单元数 | 入 | int | 10 | 神经元个数 |
| 使用偏置 | 入 | bool | true | 是否含偏置 b |
| **上游模型** | 入 | Model | 空 | **可选**：接上一张层卡的「模型」，把多层串成一条链 |
| 层元数据 | 出 | Layer | - | 接到模型构建卡（需多连线） |
| **模型** | 出 | Model | - | **= 上游各层 + 本层**，直接接训练卡的「模型」端口 |

> ⚠️ **一个输入端口默认只能接一根线**（拖第二根会顶掉第一根）。两种接法二选一：
> ① **串联（推荐）**：`层卡①.模型 → 层卡②.上游模型 → … → 训练卡.模型`，每根线 1 对 1；
> ② **并联**：各层卡的「层元数据」都连到模型构建卡的「层列表」，需右键端口 →「**添加多个数据连接**」逐根加。
> 激活函数卡端口与全连接层卡同构（「激活类型」代替「单元数」）。两法**不要混用**。

### 激活函数（Activation）

为其归属的全连接层声明激活类型。支持：`leaky_relu`（默认）、`relu`、`sigmoid`、`tanh`、`linear`。
非法值会警告并回退为 leaky_relu。

### 模型构建（ModelBuilder）

把多条层元数据按**连线顺序**聚合成 Model。空结构时警告。

### 训练模型（TrainModel）

| 端口 | 方向 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| 模型 | 入 | Model | - | 可选；不接则用默认结构 {输入维, max(4,2×输入维), 输出维} |
| 数据集 | 入 | Dataset | - | 必需 |
| 迭代轮数 | 入 | int | 10000 | epochs |
| 学习率 | 入 | double | 0.0001 | 全批量梯度下降配套取小学习率 |
| 随机种子 | 入 | int | 42 | 相同种子结果可复现 |
| 测试集 | 入 | Dataset | 空 | **可选（新增）**：连上后自动算测试集 R²/MSE/MAE，并生成「训练集/测试集 1×2 对照图」 |
| 模型名称 | 入 | string | "" | **可选（新增）**：图表标题与对比图例用，如 `ANN Model1`；留空自动命名为 `ANN 3-10-1` |
| 训练结果 | 出 | TrainingResult | - | 网络 + 每轮 MSE 历史 |
| 模型报告 | 出 | ModelReport | - | **新增**：训练/测试指标 + 逐样本预测，接到「结果对比」卡做多模型对比 |

内部算法（与 Python 版一致）：He 权重初始化、零偏置、Leaky ReLU 隐藏层、恒等输出层、MSE 损失、每轮全样本梯度和更新一次。

> **图表**（右键卡片 →「显示图表窗口」）：① 训练损失曲线（复刻 `ANN_ModelX_Train_MSE.png`，左全量+右收敛细节）② 预测vs真实（蓝=训练集、绿=测试集、红虚线 y=x，复刻 `ANN_ModelX.png`）③ 逐样本对比 ④ 网络结构。

### 模型推理（Predict）

| 端口 | 方向 | 类型 | 说明 |
|---|---|---|---|
| 模型 | 入 | object | 接训练卡的 TrainingResult（自动解包） |
| 输入数据 | 入 | object | Dataset（自动取 X）/ double[][] / double[] |
| 预测结果 | 出 | double[][] | 每行一个样本的预测输出 |

### 模型评估（Evaluate）

计算 R² / MSE / MAE（公式与 Python 版一致）。

| 端口 | 方向 | 类型 | 说明 |
|---|---|---|---|
| 真实标签 | 入 | object | Dataset（自动取 Y）/ double[][] / double[] |
| 预测结果 | 入 | object | 推理卡输出的 double[][] |
| 模型名称 | 入 | string | **新增（可选）**：图表标题/图例用，留空自动命名 |
| 决定系数R2 / 均方误差MSE / 平均绝对误差MAE | 出 | double ×3 | 三大指标 |
| 评估摘要 | 出 | string | 一行文字汇总（截图写报告方便） |
| 模型报告 | 出 | ModelReport | **新增**：本次评估的指标与逐样本预测，接到「结果对比」卡 |

### 结果对比（Compare）★ 新增

把所有模型的「模型报告」汇总到本卡，即可一键生成 5 页对比图。**三种入口任选一条**（自动去重）：

| 入口 | 路线 | 说明 |
|---|---|---|
| **报告1、报告2 … 报告5** | ① 推荐 | 一模型一个入口，**每口一根线**，不需要任何多连线操作 |
| 模型集合 (ModelSet) | ② | 用各模型卡的「报告汇总」串成一条链，末端接这个口 |
| 多连线报告 (ListByList) | ③ | 同一口接多根「模型报告」（需右键端口「添加多个数据连接」） |
| 对比标题 | — | 默认「混凝土抗压强度预测」 |
| 对比摘要（出） | — | 各模型指标 + 自动排名 + 结论文字 |

生成的 5 页图：① 精度总览（R²/MSE/MAE 分组柱状图 + R²-MSE 定位图）② 全模型对照（多模型散点叠在同一张 y=x 图上）③ 逐样本对比（每个样本上各模型预测 vs 真实）④ 训练损失对比（对数轴叠加）⑤ 指标明细表（排名 + 结论 + 横向 R² 排名条形图）。

### 张量查看器（TensorViewer）

接任意对象输出文字摘要：Dataset 维度 / Model 层列表 / TrainingResult 收敛情况 / 数组预览。调试必备。

## 5. 快速自检：XOR 冒烟测试（可选）

首次部署后建议先用内置 XOR 数据验证整条链路：

1. 拖出 **输入数据**（路径留空 → 自动生成 4 条 XOR 样本）；
2. 搭结构：`全连接层(单元数=8)` 的层元数据 → **模型构建**；
3. 模型构建 → **训练模型**（迭代轮数=2000，学习率=0.1）；同时输入数据的数据集 → 训练模型；
4. 训练结果 → **张量查看器**，应看到类似：

   ```
   TrainingResult: 结构=3-8-1, 轮数=2000, 最终MSE≈0.00x
   ```

看到 MSE 明显下降即说明环境部署成功。

> 注意：XOR 测试学习率用 0.1；混凝土回归任务请回到默认 0.0001。

## 6. 模型一（3-10-1）完整搭建步骤

对应 Python 版 `ANN_model1`：输入层 3 神经元 → 隐藏层 10 神经元（Leaky ReLU）→ 输出层 1 神经元（恒等）。

### 步骤 1：放置卡片

| 卡片 | 关键参数 |
|---|---|
| 输入数据 A | 数据路径 = `...\train.csv`，其余默认 |
| 全连接层 H1 | 单元数 = **10** |
| 激活函数 Act1 | 激活类型 = **leaky_relu** |
| 全连接层 OUT | 单元数 = **1**（末层自动线性输出，无需接激活卡） |
| 模型构建 MB | 模型名 = ANN_Model1 |

### 步骤 2：连接结构线（顺序不能错！）

```
H1.层元数据 → Act1 → Act1.层元数据 → OUT → OUT.层元数据 → MB.层列表
（三条 Layer 连线的先后顺序 = 网络层顺序：Dense(10) → leaky_relu → Dense(1)）
```

### 步骤 3：连接数据与训练

```
A.数据集 ──→ TrainModel.数据集
MB.模型  ──→ TrainModel.模型
TrainModel 参数：迭代轮数=10000，学习率=0.0001，随机种子=42
```

### 步骤 4：运行并确认

训练完成后日志输出示例：

```
TrainModelCard: 训练完成。结构=3-10-1（激活:leaky_relu/linear），
epochs=10000，lr=0.0001，seed=42，最终MSE=0.xxxxxx
```

把 TrainingResult 接到张量查看器可随时复核结构与收敛情况。

## 7. 模型二（3-5-5-1）搭建要点

对应 Python 版 `ANN_model2`：3 → 隐藏层1(5) → 隐藏层2(5) → 1。

结构链比模型一多一层：

```
Dense(5) → Activation(leaky_relu) → Dense(5) → Activation(leaky_relu) → Dense(1)
```

其余连线、训练参数与模型一完全相同（epochs=10000，lr=0.0001）。建议复制模型一的卡片组后修改，两个模型的日志/摘要中通过结构文本 `3-5-5-1` 与 `3-10-1` 区分。

> 若省略激活函数卡也可以：未声明的中间层自动使用 leaky_relu，末层自动 linear——效果与本节手动声明等价。显式画出激活卡的好处是结构一目了然，便于报告截图。

## 8. 模型评估工作流

每个模型需要两组指标（与报告表格对应）：**训练集自评** 与 **测试集泛化评估**。

### 8.1 测试集评估画布

再拖一张 **输入数据 B**（路径=`test.csv`），然后：

```
B.数据集 ──→ Predict.输入数据
TrainModel.训练结果 ──→ Predict.模型
B.数据集 ──→ Evaluate.真实标签        ← 自动取 test.csv 的标签列 Y
Predict.预测结果 ──→ Evaluate.预测结果
Evaluate 四个输出口 → R²/MSE/MAE/摘要
```

### 8.2 训练集自评画布

把上图中 B 换成输入数据 A（train.csv）即可复用同一套连线。

### 8.3 结果对照

日志与评估摘要格式如下（可直接与 Python 版 `print` 输出互相校验）：

```
EvaluateCard: 评估完成。样本数=16，R²=0.xxxx，MSE=x.xxxx，MAE=x.xxxx
```

| 指标 | 公式 | 期望 |
|---|---|---|
| R² | 1 - RSS/TSS | 越接近 1 越好 |
| MSE | Σ(y-ŷ)²/N | 越接近 0 越好 |
| MAE | Σ\|y-ŷ\|/N | 越接近 0 越好 |

> 由于 C# 版与 Python 版的随机初始化序列不同，两者数值不会逐位相等，但应在同一量级；固定随机种子后，C# 版自身每次运行结果完全可复现。

## 9. 参数说明与调优建议

### 9.1 与 Python 版参数对照表

| 参数 | Python 版 | C# 卡片 | 默认值 |
|---|---|---|---|
| 隐藏层激活 | Leaky ReLU α=0.01 | 激活函数卡 leaky_relu | 一致 |
| 输出层激活 | identity | 末层 Dense 自动 linear | 一致 |
| 权重初始化 | He 初始化 | SimpleNN He 初始化 | 一致 |
| 偏置初始化 | 0 | 0 | 一致 |
| 损失函数 | MSE | 固定 MSE | 一致 |
| 优化方式 | 全批量梯度下降（梯度求和） | 同左 | 一致 |
| 学习率 | 0.0001 | 训练卡·学习率 | 0.0001 |
| 训练轮数 | 10000 | 训练卡·迭代轮数 | 10000 |

### 9.2 调优建议

- **loss 不降或震荡**：学习率偏大。本项目梯度是全样本求和口径，务必从小学习率起步（默认 0.0001 即为此设计），可按 0.5× 递减试探；
- **收敛太慢**：适当加大迭代轮数（如 20000），或微升学习率（×2）观察；
- **结果每次都一样/不一样**：随机种子固定则完全可复现；换种子（如 1、7、42）可得不同初始化的对比实验，报告中可作为多组试验数据；
- **R² 低但 loss 已很小**：检查是否误将标准化后的强度当标签，或训练/测试集用了不同标准化参数。

## 10. 常见问题 FAQ

**Q1：CSV 加载后中文列名乱码？**
本项目已自动识别 UTF-8/GB18030。若仍异常，请用 Excel 另存为"CSV UTF-8"。列名仅影响"按名称指定特征/标签列"，按索引指定则不受影响。

**Q2：提示"暂不支持 .xlsx"？**
本项目只读 CSV。请先另存为 CSV（原因：砍掉 NPOI 反射依赖，保持工程精简稳定）。

**Q3：训练卡报"未收到有效数据集"？**
检查输入数据卡是否成功执行（看其日志）、Dataset 连线是否接到训练卡的"数据集"端口。

**Q4：推理卡报"模型无效"？**
必须连**训练模型卡**的输出（TrainingResult）。直接连"模型构建卡"的结构是不行的——未经训练的网络没有权重。

**Q5：评估卡报"样本数不一致"？**
"真实标签"与"预测结果"必须来自同一份数据：同一个 Dataset 既喂给推理卡（取 X）又喂给评估卡（取 Y），两者行数天然一致。

**Q6：VS 断点灰色不命中？**
调试 → 选项 → 取消勾选"启用仅我的代码"；确认以 Release 编译且 `.pdb` 已随 `.crd` 部署。详见 README。

## 11. 已知限制

1. 仅支持 CSV 数据源（Excel 请先转存）；
2. 损失函数固定 MSE、优化器固定全批量梯度下降（与课程设计范围一致）；
3. 引号跨行的 CSV 字段不支持（课程数据不涉及）;
4. 多条层连线的顺序依赖 GAMA ListByList 的收集顺序，请严格按"从输入侧到输出侧"依次连线；
5. 大规模数据/深层网络的性能未经优化（纯 C# 循环实现，教学规模数据毫秒级~秒级）。

### 12.2 搭一张「五模型对比」画布（推荐演示流程）

```
输入数据A(内置 train) ─┬→ 训练卡①（模型名称 ANN Model1，测试集接 B）─┐
                      └→ 训练卡②（模型名称 ANN Model2，测试集接 B）─┤
输入数据B(内置 test) ──→ 训练卡①②.测试集 / 线性模型①②③.测试集        │
线性模型①(simple)  模型名称=线性·简单      ──────────────────────────┤
线性模型②(interaction) 模型名称=线性·交互  ──────────────────────────┤
线性模型③(poly)    模型名称=线性·多项式    ──────────────────────────┘
                                                                     ↓ 汇总链（每根 1 对 1）
训练卡①.报告汇总 → 训练卡②.上游汇总 → 线性①.上游汇总 → 线性②.上游汇总 → 线性③.上游汇总
                                                           线性③.报告汇总 → 结果对比卡.模型集合
```

**层结构的两种接法**：① 串联（推荐）`层卡①.模型 → 层卡②.上游模型 → … → 训练卡.模型`；
② 并联到模型构建卡（右键端口「添加多个数据连接」逐根加）。

**报告汇总的两种接法**：① 上面的汇总链（推荐）；② 各卡「模型报告」逐根接到对比卡「模型报告」端口（同样需要「添加多个数据连接」）。

一次运行即可得到全部 5 个模型的训练集/测试集指标，并在「结果对比」卡里自动排名、自动出结论。
指标表里 C# 版线性模型的数值与课程设计报告**逐位一致**（simple 0.9352 / interaction 0.9495 / poly 0.9601 训练集 R²）。

### 12.3 常见问题

- **导出没反应/报错**：确认工程以 Release 编译且 `.crd` 已部署（编译后自动复制）；E-GAMA 需**重启**后才加载新卡片。
- **图表空白**：先运行卡片（生成图表数据），再点右键菜单；未运行时菜单只显示提示。
- **对比图只有 1 个模型**：检查每个模型卡的「模型报告」是否都连到了结果对比卡（**多根线**，不是串成一根）。
- **想加报告的图**：直接用导出的 PNG（3200×1900，2 倍分辨率）；不要截图，压缩会掉质量。
